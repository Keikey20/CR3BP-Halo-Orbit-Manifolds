# CR3BP Halo Orbit and Invariant Manifolds

A MATLAB academic project exploring halo orbits and invariant manifolds in the Circular Restricted Three-Body Problem (CR3BP).

The project focuses on computing periodic halo orbits, studying their stability and visualising the behaviour of stable and unstable manifolds through numerical simulations.

## What I Worked On

- Halo orbit computation and correction.
- Numerical analysis of orbital stability.
- Monodromy matrix and eigenvalue analysis.
- Stable and unstable manifold propagation.
- Poincaré section visualisation.

## Tools & Methods

MATLAB · CR3BP · Orbital Mechanics · Numerical Integration · Dynamical Systems

## About

This project was developed as part of my Aerospace Engineering studies, providing practical experience with orbital dynamics and numerical methods used in astrodynamics.
