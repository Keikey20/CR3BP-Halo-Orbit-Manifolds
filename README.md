# CR3BP Halo Orbit and Invariant Manifold Analysis

A MATLAB-based academic project focused on the analysis of halo orbits and invariant manifolds within the Circular Restricted Three-Body Problem (CR3BP).

The project explores periodic orbit computation, orbital stability and the behaviour of stable and unstable invariant manifolds in a three-body gravitational system.

## Project Overview

The Circular Restricted Three-Body Problem provides a mathematical framework for studying the motion of a small body under the gravitational influence of two larger celestial bodies.

This project investigates halo orbit dynamics and associated manifold structures through numerical simulation using MATLAB.

## Key Features

- Circular Restricted Three-Body Problem (CR3BP) modelling.
- Halo orbit computation and differential correction.
- Variational equations and state transition matrix analysis.
- Monodromy matrix and eigenvalue analysis.
- Stable and unstable invariant manifold propagation.
- Poincaré section analysis.
- Numerical investigation of orbital dynamics and stability.

## Methodology

The project uses numerical integration and dynamical systems techniques to investigate periodic halo orbits and their associated invariant manifolds.

The monodromy matrix and its eigenstructure are used to examine local orbital stability and identify directions associated with stable and unstable manifold behaviour.

## Technologies and Methods

- MATLAB
- Circular Restricted Three-Body Problem (CR3BP)
- Numerical Integration
- Differential Correction
- Variational Equations
- Monodromy Matrix
- Eigenvalue and Eigenvector Analysis
- Invariant Manifolds
- Poincaré Sections

## Project Scope and Limitations

This project was developed as an academic numerical study of CR3BP halo orbit dynamics and invariant manifolds.

The results depend on the implemented numerical models, correction procedures and simulation assumptions. The project is intended for educational and computational exploration rather than operational mission design or flight validation.
